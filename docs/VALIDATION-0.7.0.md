# Steam × GGSEL 0.7.0: собственная страница товара

Версия 0.7.0 заменяет подход 0.6.0: открытие оригинального сайта не считается выполнением требования о странице внутри текущего Steam Store.

## Техническое решение

Выбран вариант B. GGSEL отвечает CSP `frame-ancestors 'self' https://metrika.yandex.ru`, поэтому iframe на Steam запрещён. API Millennium `add_browser_css` подключает стили к существующему браузерному документу, но не создаёт встраиваемый WebView. Поддерживаемого API для размещения отдельного WebView внутри DOM магазина в изученных интерфейсах не найдено. Ограничения сайта не обходятся.

Страница создаётся непосредственно в `.responsive_page_template_content` текущего документа Steam. Сохраняются оригинальные узлы, их состояние, раскрытые условия и прокрутка; они возвращаются при закрытии. Адрес остаётся `store.steampowered.com/app/.../#ggsel-product-ID`. На этапе просмотра отсутствуют iframe, window.open и переход на GGSEL. Старые CSS-hook, внешний merchant shell и RPC его контекста удалены.

Данные загружаются существующим локальным Lua HTTPS-провайдером с проверкой TLS, ограничениями запросов и кэшем. Перед показом проверяются точный ID товара, игра, платформа, название, издание, тип и ID продавца. Длинные описания React Flight читаются как UTF-8 записи с указанной длиной; скрипты не исполняются. Merchant HTML не вставляется в Steam: описание преобразуется в текст. Изображения допускаются только с HTTPS img.ggsel.net. Неизвестные данные явно обозначаются; ошибки скрывают цену и оформление.

Рейтинг продавца, количество его отзывов и положительные отзывы о товаре показаны раздельно. Тексты индивидуальных отзывов не запрашиваются и не выдумываются. Условия вариантов включают исходные модификаторы цены. Цена остаётся рекламируемой RUB-ценой; окончательный расчёт производится GGSEL.

## Проверки

- Windows, Millennium 3.5.0, Bun 1.4.2. TypeScript и Starlight проходят; контейнер содержит все четыре секции.
- Автоматические тесты проверяют точную идентичность, безопасные ссылки, UTF-8 описания, отсутствие iframe/перехода со Steam, сохранение исходных узлов, раскрытых условий и полей, отказ при неверном ID.
- Проверка публичных страниц пяти предложений Cyberpunk подтверждает возможность прочитать настоящие изображения и полные описания, цены и продавцов, включая аккаунт и Ultimate.
- Визуально в настоящем Steam нажато предложение Indiana Jones: собственная полноразмерная страница, реальное изображение, описание, Standard Steam Key, 2103 ₽, RU/UA-CIS, Fabulou5, рейтинг 4.9/5. Адрес остался на Steam с внутренним якорем.
- При повторной проверке окончательной сборки GGSEL уже вернул 2187 ₽ для этого же товара: обновлённая цена одинаково показана в предложении Steam и на собственной странице. Цена 2103 ₽ выше относится к более раннему запросу, не является константой приложения.

- В настоящем Steam нажаты также Cyberpunk Account (921,99 ₽, VIAGAMES, ID 102326188) и Steam Gift (от 2749 ₽, SjMarket, ID 4292081). Реальные изображения и длинные описания отображаются на Steam origin. У Gift сохранены исходные регионы и доплаты; аккаунт явно обозначен аккаунтом.
- На окончательной сборке проверен Indiana Premium (ID 103109878): 2808 ₽, Happy Games, Steam Key, PREMIUM, RU+CIS+Ukraine. Собственная страница остаётся в том же документе Steam; возврат работает. Снимок: `diagnostics/steam-native-indiana-premium-070.png`.
- Проверены возврат собственной кнопкой и штатной стрелкой Steam. Прокрутка и раскрытые условия исходного предложения сохраняются; оригинальные Steam-кнопки остаются прежними.
- Финальная сборка: 31 тест, 120 assertions, 0 ошибок. Проверка TypeScript и всех четырёх секций `.star` успешна; установленный плагин enabled/running.
- Кнопки предложений — настоящие `button`, без href: внешнюю вкладку нельзя открыть средней кнопкой мыши на предложении. Единственная внешняя ссылка находится на этапе оформления.

Локальные снимки проверки: `diagnostics/steam-native-indiana-070.png`, `steam-native-cyberpunk-account-070.png`, `steam-native-cyberpunk-gift-070.png`, `steam-native-cyberpunk-return-070.png`. Снимки и приватные журналы не включены в дистрибутив.

## Оформление и ограничения

Единственная внешняя ссылка на странице — «Перейти к оформлению на GGSEL». Рядом заранее указано, что откроется настоящий сайт во внешнем представлении браузера. Это точный проверенный URL товара, а не выдуманный платёжный endpoint. Выбор вариантов, заказ и оплата выполняются пользователем на GGSEL. Прямой безопасный checkout API не установлен; форма оплаты в Steam не имитируется.

Платёжные переходы и реальные покупки не тестировались. Плагин не читает платёжные реквизиты, cookies и авторизацию. Новых изменений Clash в 0.7.0 нет. `steamapps`, игры и сохранения не изменялись. Резервные копии установленных артефактов находятся в локальном `diagnostics/installed-*.star`, приватные настройки прокси не входят в выпуск.

Первичные источники API: [Millennium Lua API](https://github.com/SteamClientHomebrew/Millennium/blob/main/src/lua_host/api/millennium.cc), [WebKit bindings](https://github.com/SteamClientHomebrew/Millennium/blob/main/src/bindings/webkit.cc), [Target URL checks](https://github.com/SteamClientHomebrew/Millennium/blob/main/src/engine/target_url.cc). CSP подтверждён реальным ответом GGSEL, локальная диагностика `diagnostics/indiana-product-headers.txt` (не распространяется).
