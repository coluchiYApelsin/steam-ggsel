# Проверка Steam × GGSEL 0.8.1 — 11 октября 2026

## Реально реализовано

- Перед переходом повторно проверяются настоящая карточка, цена и схема опций. Изменение схемы блокирует продолжение и требует заново открыть карточку.
- Экран явного подтверждения содержит продавца, товар, варианты и цену. Ссылка ведёт на реальную HTTPS-карточку, использует предвыбор одиночных вариантов, исключает текстовые данные и действует 15 секунд после quote.
- Сохранённая/отсоединённая ссылка блокируется после изменения выбора или закрытия карточки. После перехода показано, что плагин не создал заказ и статус оплаты неизвестен.
- Проверяются повреждённые опции, повторяющиеся ID, неизвестные ID выбора и некорректные timestamps quote. Поля Steam Guard, 2FA, CVV/CVC и банковских карт отклоняются вместе с паролями и токенами; проверяются также comment/placeholder.
- Диагностика сохраняет настоящий HTTP-код ответа вместе с внутренним идентификатором ошибки. Произвольные server bodies не отображаются. 403 и другие ошибки доступа не запускают поиск альтернативных каталогов. Отсутствующий/неправильный HTML Content-Type отклоняется.
- README синхронизирован, оригинальный HANDOFF сохранён с дополнением. Прямое создание заказов и интеграция с платежами не добавлены.

## Автоматические проверки

BUILD.cmd: **49 тестов, 219 expect-проверок, 0 ошибок**; TypeScript, frozen install, Starlight и четыре секции `.star` проходят. Lua-тесты дополнительно используют внутренние assert. Добавлены проверки повреждённых/секретных опций, timestamps, HTTP-диагностики, изменившейся схемы и отсоединённых ссылок. HTTP-моки запрещают buy/orders, cookies, Authorization, выключенный TLS и редиректы. Последняя проверка дополнительно покрывает null в результатах поиска и сохранение ошибки парсера вместо ошибочного кода `ok`.

Живой read-only `bun scripts/check-options-live.ts`: товар 5283641, Standard 2990, DLC 3490, Ultimate 4380 RUB при исходном регионе на время проверки. Эти значения не фиксируются как рабочие цены. Текущий codec сайта заново проверен по публичным статическим JS; детали — [CHECKOUT-RESEARCH.md](CHECKOUT-RESEARCH.md).

## Неподтверждённое и требующее поддержки GGSEL

Кнопка «Купить» на GGSEL не нажималась; формы не отправлялись. Заказ, финальный checkout, авторизация, оплата/3DS, перенос вариантов в конечный заказ, callback и автоматическое закрытие окна после оплаты не проверены. Поддерживаемого стороннего покупательского API в изученной официальной документации не найдено; внутренние endpoints не вызываются. Полный сценарий до оплаты внутри Steam требует официального контракта/разрешения GGSEL.

S.T.A.L.K.E.R. 2 всё ещё не имеет подтверждённого каталога. Универсальное сопоставление локализованных названий не реализовано. Проверки игры, платформы, продавца и издания не ослаблены. steamapps, установленные игры и личные данные Steam не изменялись; реальные заказы и покупки не совершались.
