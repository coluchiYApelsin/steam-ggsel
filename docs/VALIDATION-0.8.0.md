# Проверка Steam × GGSEL 0.8.0 — 10 октября 2026

Статус: рабочая проверенная часть сценария реализована; полное техническое задание пока не закрыто. Оформление заказа и перенос параметров в конечный заказ не проверены.

## Реализовано

- Полноценная собственная страница в текущем DOM Steam Store. Исходная страница, прокрутка и выбор сохраняются при закрытии/возврате в пределах документа; после перезагрузки выбор сбрасывается.
- Реальные варианты radio/select/checkbox и несекретные текстовые поля из конкретного товара. Неизвестные схемы, поля паролей и неоднозначные издания отклоняются. Переключатель отсутствует у товара без вариантов.
- При изменении выбора старая цена сразу скрывается. Получаются свежая карточка и серверная цена комбинации. Никакого самостоятельного сложения модификаторов. Перед продолжением выполняется новый запрос; изменение цены требует явного подтверждения. Неподтверждённая цена блокирует продолжение.
- Реальные описание, изображение, продавец, статистика и до трёх отзывов; предупреждение о сторонней площадке и Steam Account.
- Поиск настоящих адресов каталогов через публичный интерфейс GGSEL, включая числовые суффиксы. Нормализация апострофов, торговых знаков, пунктуации, &/and и точечных аббревиатур. Каталог и каждый товар проверяются отдельно.
- DOOM: привязка строго AppID 379720 + название DOOM к реальному каталогу doom-2016 / DOOM (2016). Другие части серии не получают эту привязку.
- «Повторить» обходит локальный кэш и выполняет новый запрос.

- Millennium загружает 0.8.0; разделы предложений Cyberpunk Standard/Ultimate и Indiana Standard/Premium отображаются под штатными блоками.
- Cyberpunk, KupiBaka, товар 5283641: Standard 2990 RUB → Ultimate 4380 RUB; другой реальный вариант региона 5580 RUB; Ukraine 4930 RUB. Это наблюдения времени проверки, не фиксированные цены плагина.

## Проверенные публичные механизмы

BUILD.cmd: 42 теста, 174 проверки, 0 ошибок; TypeScript и проверка четырёх секций Starlight прошли. Тесты покрывают изменение цены перед оплатой, отказ сети, инвалидирование старой цены, сохранение выбора, несовместимые параметры, запрещённые поля и отрицательные совпадения каталога. Дополнительная живая проверка: `bun scripts/check-options-live.ts` — Standard 2990, DLC Phantom 3490, Ultimate 4380 RUB для реального региона по умолчанию на момент запроса.

У настоящего клиента GGSEL обнаружены и отдельно запрошены без авторизации:

- GET https://api.ggsel.com/goods/5283641/price?currency=RUB&unit_count=1&options%5B448562%5D=1177048&options%5B448549%5D=1177027
- GET https://api.ggsel.com/goods/102086349/reviews?page=1&limit=3&lang=en
- POST https://api.ggsel.com/elastic/goods/query-categories с search_term, lang=en, limit=5 — только поиск, без создания заказа.

Публичный JS карточки читает query `option=option_radio_448562_1177048_option_radio_448549_1177027`. Реализован этот предвыбор для одиночных дискретных параметров. Текст и несколько флажков в URL не передаются; показано предупреждение о повторном вводе. Применение параметров оригинальной страницей и сохранение в конечном checkout визуально не подтверждены; пользователь обязан сверить выбор на GGSEL. POST /ecom/buy и создание orders не вызываются.

Millennium HTTP POST использует сигнатуру http.post(url, payload, options): https://docs.steambrew.app/plugins/lua/http. Все запросы проверяют TLS, не следуют редиректам, ограничены по времени/размеру/частоте. Ключей продавца, авторизационных cookies и платёжных данных нет.

## Оставшиеся ограничения

- Количество склада у ряда вариантов null. Подтверждены активность карточки, отсутствие явного запрета варианта и серверная цена; резервирования и гарантии наличия нет.
- GGSEL не всегда даёт отдельное описание/тип/условия для каждого варианта. Общие условия продавца показываются без выдуманных изменений. Неоднозначные комбинированные селекторы скрываются.
- Серверный расчёт количества, отличный от одной единицы, не поддерживается. Секретные поля не собираются.
- S.T.A.L.K.E.R. 2: публичный поиск по полному названию возвращает посторонние категории, по краткому — пустой результат. Такие результаты не принимаются. Универсальное сопоставление локализованных названий ещё не реализовано.
- Живые каталоги проверены также для DOOM Eternal (6 подходящих предложений), Baldur’s Gate 3 (7), DREDGE (12), DOOM (2016) (7). Для них полная визуальная проверка всех карточек ещё не завершена.
- iframe запрещён CSP GGSEL. Собственная страница работает в Steam; настоящая авторизация, checkout, 3DS и платёжный провайдер остаются внешними и не тестировались покупкой.
- Публичные внутренние интерфейсы GGSEL могут измениться без объявления. Ошибки сети, MIME, разбора, другой каталог и неподтверждённое соответствие обрабатываются отдельно.

Перед каждым обновлением установленного .star создана резервная копия. steamapps не изменялся, заказы и покупки не совершались.
