# Оформление заказа: техническая проверка 11 октября 2026

## Поддерживаемый контракт

Официальная [страница API GGSEL](https://ggsel.net/en/api-ggsel) перенаправляет на [Seller API](https://seller.ggsel.com/docs). [V2](https://seller.ggsel.com/docs/v2/seller-api-v-2) требует ключ продавца. Раздел [Orders V1](https://seller.ggsel.com/docs/return-last-sales) описывает чтение продаж, информацию о заказе и проверку уникального кода. Это не найденный контракт создания покупательского заказа между произвольными продавцами и сторонним плагином.

В публичном JS самого магазина присутствуют POST `/ecom/buy` и `/api_customer/v1/orders`, а также авторизованные запросы статуса и оплаты. Наличие клиентского кода не доказывает разрешение сторонней интеграции, стабильность схемы или возможность безопасного получения статуса. Эти endpoints не вызывались и не добавлены в backend. Никакие реальные заказы, счета или списания для исследования не создавались.

Вывод ограничен исследованными официальными страницами: документированного поддерживаемого покупательского API не найдено. Для прямого оформления нужна поддержка GGSEL: условия интеграции, схема опций и допустимых данных, quote/заказ с идемпотентностью, официальный HTTPS URL оплаты, способ аутентификации покупателя и достоверный подписанный callback либо авторизованный опрос статуса. Ключ продавца не следует просить у покупателя.

## Передача выбора

11 октября заново прочитаны настоящая публичная карточка товара 5283641 и её статические JS-файлы. Текущий клиент кодирует пары `name/value` в `option=option_radio_<id>_<value>_...`; при загрузке извлекает значения по именам опций и сверяет с `variants`. Для checkbox клиент создаёт массив с одним значением. Плагин передаёт только одиночные дискретные варианты, текст в URL не помещает.

Источники проверки текущего клиента:

- https://static.ggsel.com/ggsel/UlI2Qz6u8p70-rVBiR7DP/_next/static/chunks/0e.q8ym.31rm6.js — codec; SHA-256 `604099e7b195e9085855f49589581dec78e7a4012ccec1f88a4fcc57a6ec421c`.
- https://static.ggsel.com/ggsel/UlI2Qz6u8p70-rVBiR7DP/_next/static/chunks/17k._9h8u9-~y.js — применение предвыбора к форме/quote; SHA-256 `670f5d76dc279fa222c7edd5c7f7b40345a646b9da7f1f1288019d6c233a853f`.

Это наблюдение реализации сайта, не официальный API-контракт. JS исследовался как текст; в Steam не исполняется. Автоматические запросы страницы с query `option` не делались: robots.txt исключает такие URL из обхода. Визуальная проверка выполнялась обычным переходом по ссылке из Steam, без обхода защит.

В настоящем Steam 0.8.1 подтверждение открыло отдельное окно Steam Browser. На странице GGSEL визуально выбран **Cyberpunk 2077 Ultimate Edition** и регион **Россия/РБ (со сменой региона на Укр. UA)**, соответствующие ID 1177048 и 1177022. GGSEL показывал 52 USD; quote плагина — 4380 RUB. Это наблюдавшиеся цены в разных валютах, не обещание равенства итогов или фиксированного курса. Кнопка «Купить» на GGSEL не нажималась. Перенос выбора в конечный заказ, комиссии и доступность платёжных методов не проверены.

Текст и несколько checkbox требуют повторного ввода. Очистка варианта с default тоже не имеет доказанного URL-представления и помечается как неполная передача. Плагин показывает сводку выбора и требует сверить её на GGSEL.

## Отдельное окно и результат оплаты

Используется обычная HTTPS-ссылка с `target=_blank` и `rel=noopener noreferrer`. В этой установке Millennium 3.5.0/Steam она реально открыла отдельное окно с сайтом GGSEL. В других клиентах обработчик ссылок может открыть внешний браузер; гарантии формы окна нет. [Документация Millennium](https://docs.steambrew.app/plugins/introduction/environment) о дочерних окнах SharedJSContext не является API платёжного окна в Store WebView.

Плагин не внедряет код в окно GGSEL, не читает cookies, авторизацию или данные провайдера, не удерживает opener. Закрытие окна, возврат фокуса и редирект сами по себе не доказывают оплату. Без поддерживаемого канала статуса автоматическое закрытие после успешной оплаты и фактический статус заказа внутри Steam не реализованы. После перехода честно отображается неизвестный статус. В тесте окно закрыто вручную; это не событие успешной оплаты.

Универсальная эквивалентность переводов Steam и GGSEL остаётся неподтверждённой. Нормализация пунктуации и проверенная привязка DOOM сохранены; новые переводные алиасы не придуманы. Нужен поддерживаемый каталог с AppID либо независимо подтверждённые пары AppID/названия/корневой категории.
