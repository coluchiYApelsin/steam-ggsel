## Границы подтверждения

- На всех четырёх играх настоящее отдельное окно открыло официальный товар GGSEL. HTTPS product URL проверяется кодом перед ссылкой; ID/товар и доступные параметры сопоставлены по видимому содержимому. Конечная `window.location` и вся цепочка браузерных redirect независимо не считаны: Steam Browser не показал адресную строку. Полный redirect trace не заявляется.
- Публичный JS GGSEL связывает Buy с submit формы, затем POST создания заказа, UUID и переходом на `/order/<uuid>`. Создание настоящего заказа запрещено условиями этой проверки; Buy, внутренние order/buy endpoints и платёжные формы не отправлялись. До выбора платёжного метода **ни для одной игры не дошли**.
- Noopener/noreferrer и отдельный браузерный контекст используются; безопасность платёжного провайдера, 3DS и его окон не тестировалась. Авторизованный статус, подписанный callback и автоматическое закрытие после оплаты требуют разрешённого контракта GGSEL. Закрытие окна не доказывает оплату.
- Скрытие старой цены, гонки ответов, смена schema/price, истечение ссылки, пустые результаты, HTTP ошибки и чужие игры покрыты автоматическими тестами. Искусственные сбои сети в настоящем Steam для каждой игры отдельно не вводились. Реальные 405 для Ragnarök/Hollow Knight наблюдались и исправлены; полный GUI fault matrix не заявляется.
- Количество у выбранных товаров — одна единица; отсутствующие издания/опции и калькулятор количества не выдумывались.

## Подготовка публикации

Git origin отсутствовал. История и рабочие исходники проверяются до публичного push; диагностика, инструменты, зависимости и `.star` игнорируются. В 11 исходных коммитах проверены 130 Git blobs: совпадений с высокодостоверными шаблонами секретов не найдено. Это проверка по шаблонам плюс ручной обзор, не математическая гарантия.

Публикация пока **не подтверждена**: GitHub CLI требует официальной авторизации, автоматический запуск Chrome отклонён проверкой разрешений («blocked by policy»), даже после явного разрешения пользователя. Запрошено завершение обычного device login пользователем; cookies/токены не извлекались. Ссылка на репозиторий не выдумывается. При незавершённой авторизации/push Windows не выключается.
