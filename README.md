# Steam × GGSEL 0.8.2

**Steam × GGSEL — независимый неофициальный проект с доступным исходным кодом. Не разработан, не одобрен, не поддерживается и не связан с Valve Corporation, Steam или GGSEL. Все покупки осуществляются у сторонних продавцов на соответствующей торговой площадке.

**Статус: активная разработка (Beta). Плагин находится на стадии тестирования. Некоторые функции могут работать нестабильно или быть недоступны.

Результаты проверки четырёх игр в настоящем Steam: [END-TO-END-VALIDATION](docs/END-TO-END-VALIDATION.md). Прямой экран оплаты не реализован: клиент GGSEL предварительно создаёт настоящий заказ, а разрешённого стороннего покупательского API не найдено. Проверенный fallback открывает официальную карточку товара в отдельном окне, сохраняя страницу Steam.

В 0.8.2 подтверждены каталоги UNCHARTED (1659420), God of War Ragnarök (2322010), Hollow Knight (367520) и R.E.P.O. (3241660). Русские названия первых двух сопоставляются только вместе с точным AppID; каталог дополнительно проверяется по фактическим данным GGSEL. Исправлен разбор UTF-8 записей Flight с длиной текста. Проверки игры, платформы и издания остаются обязательными.

На настоящей странице R.E.P.O. визуально подтверждён предвыбор Казахстана. **Все checkbox и текстовые поля нужно заполнить на GGSEL заново**: согласие Hollow Knight сайт не восстанавливает из URL. Плагин предупреждает об этом перед переходом. Наличие значения в Steam не означает, что GGSEL проверил текст или сохранил его в заказе.

В истории проекта не обнаружена собственная лицензия. Новая лицензия не назначалась; доступный исходный код сам по себе не подтверждает права распространения по OSI-лицензии. Условия инструментов и зависимости: [THIRD_PARTY](THIRD_PARTY.md).

Неофициальный Millennium-плагин с доступными исходниками: реальные предложения GGSEL под штатными блоками покупки Steam. Собственная карточка товара открывается прямо в текущем документе Steam Store, без iframe или нового окна. Страница игры и выбор сохраняются при возврате в пределах документа.

В карточке показаны проверенные товар, продавец, изображение, описание, отзывы, регион и реальные варианты. Игра, Steam-платформа, тип, продавец и издание проверяются независимо; неизвестные соответствия скрываются. Публичный поиск категорий GGSEL даёт только кандидатов, корневой каталог обязательно проверяется. Есть проверенная привязка DOOM AppID 379720 к DOOM (2016); S.T.A.L.K.E.R. 2 и универсальное сопоставление переводов пока не подтверждены.

## Выбор и оформление

После изменения вариантов прежняя цена скрывается и запрашивается реальный серверный расчёт GGSEL. Перед переходом заново проверяются карточка, схема вариантов и цена. Изменившаяся схема блокирует продолжение; изменившаяся цена требует явного подтверждения. Экран подтверждения показывает товар, продавца, выбранные параметры и свежую цену; ссылка действует 15 секунд после quote.

После отдельного подтверждения настоящая HTTPS-карточка GGSEL открывается в новом браузерном контексте. В проверенном Steam это отдельное окно Steam Browser; другие установки могут использовать внешний браузер. Предвыбор одиночных вариантов визуально проверен для KupiBaka 5283641 (Ultimate Edition и регион) и R.E.P.O. 5255891 (Казахстан). Сохранение выбора в конечном заказе не проверено. Текстовые данные, все checkbox и очистка default не имеют подтверждённого URL-представления; сверяйте выбор и заполняйте необходимые поля на GGSEL повторно.

Плагин не создаёт заказ. Поддерживаемый сторонний покупательский API в изученной официальной документации не найден, поэтому внутренние endpoints buy/orders не вызываются. После перехода статус заказа/оплаты отображается как неизвестный. Авторизация, платежи и 3DS выполняются на GGSEL/платёжном сервисе; автозакрытие после успешной оплаты не реализовано. Секретные поля (пароли, Steam Guard, 2FA, CVV/CVC и данные карты) в форме плагина запрещены. Текст не отправляется в URL или quote. Проверка наличия не резервирует товар.

GGSEL сам определяет валюту, комиссии, доступные методы и итоговую цену. В живой проверке plugin quote был в RUB, сайт показал USD. Перед оплатой обязательно сверяйте сумму, регион и условия на площадке. Подробности: [исследование checkout](docs/CHECKOUT-RESEARCH.md), [проверка 0.8.1](docs/VALIDATION-0.8.1.md), [ограничения](KNOWN_ISSUES.md).

Внешний сервер и ключи API не нужны для реализованного просмотра/quote. Публичные страницы и интерфейсы GGSEL не являются стабильным договором интеграции; ошибки HTTP, схемы или соответствия скрывают цену и оформление. Проверки доступа, капчи и запрещённые поисковые маршруты не обходятся.

## Сборка Windows

Требуются Windows x64, Node >=16 (проверен 24.21.0), Bun (проверен 1.4.2) и официальный Microsoft Visual C++ Redistributable x64:
https://aka.ms/vs/17/release/vc_redist.x64.exe

Из каталога исходников вне папки Steam:

```powershell
.\BUILD.cmd
```

Или по отдельности:

```powershell
bun install --frozen-lockfile
bun run typecheck
bun test
bun run build
```

Starlight автоматически создаёт декларации Millennium при установке зависимостей (`prepare`). Если `.millennium` отсутствует, выполните `bun run prepare`. `build` запускает закреплённый официальный компилятор, создаёт `.star` и проверяет все его секции. Журнал — `diagnostics/build-latest.txt`.

Ошибка Bun 53 в этом окружении была сокращённым кодом Windows `0xC0000135`: отсутствовал VCRUNTIME140.dll. После установки официального Runtime тот же компилятор заработал. Переустановка npm-зависимостей сама по себе этого не исправляет. npm-пакет Starlight 1.1.6 содержит бинарник, сообщающий 1.1.5; это зафиксировано в диагностике.

## Установка

В Steam должен быть установлен Millennium (проверена версия 3.5.0). Запустите:

```powershell
.\INSTALL.ps1
# При нестандартном расположении Steam:
.\INSTALL.ps1 -SteamPath 'D:\Steam'
```

Скрипт копирует только готовый `steam-ggsel.star` в `millennium/plugins`; предыдущую сборку с таким именем сохраняет в `diagnostics`. Можно скопировать файл вручную. Каталоги исходников 0.4.x не являются скомпилированным плагином и не заменяют `.star`.

Включите **Steam GGSEL Prices** в настройках Millennium, затем обновите страницу магазина. В текущей машине тестовая сборка уже установлена и включена. Она не подписана издателем.

## Обновление и удаление

Для обновления получите новую версию исходников, выполните `BUILD.cmd`, затем `INSTALL.ps1`. Скрипт сохранит предыдущую сборку в локальной `diagnostics/`. Перезагрузите интерфейс Millennium и заново откройте страницу игры. Если используете готовый файл из GitHub Release, поместите его в `dist/steam-ggsel.star` перед запуском `INSTALL.ps1` и сверяйте SHA-256 с описанием выпуска.

Для удаления отключите **Steam GGSEL Prices** в Millennium, закройте Steam и удалите только `millennium/plugins/steam-ggsel.star` из своей папки Steam. После запуска Steam плагин больше не загружается. Для возврата к предыдущей версии используйте сохранённый `.star` из `diagnostics/`.

## Поведение

- AppID определяется по `/app/<id>/`, название — по странице Steam. Есть проверенные привязки Cyberpunk 2077, DOOM (2016) и четырёх игр отчёта 0.8.2; для остальных проверяется кандидат публичного каталога по названию. Запрещённые поисковые маршруты не используются.
- Ответ GGSEL разбирается только как JSON. Его HTML и скрипты не внедряются в Steam. Название каталога обязано точно совпасть; неизвестные товары и издания скрыты.
- Отдельные Standard/Deluxe/Ultimate/Complete/Premium сопоставляются с точными заголовками блока (`h1` и текущий `h2`). Для Cyberpunk 2077 отдельно проверен набор Steam 32470: базовая игра + Phantom Liberty, соответствующий Ultimate / «Полное издание». Другие наборы, DLC и неподтверждённые варианты получают состояние без предложений.
- Показаны до пяти предложений по возрастанию цены; остальные раскрываются. Аккаунты, Steam Gift и ключи обозначаются отдельно. Условия продавца, регионы и варианты раскрываются в карточке.
- Рейтинг продавца отделён от количества отзывов о товаре. Неизвестные показатели не выдумываются. При изменяемой цене указано «от»; итог зависит от выбранного региона и условий GGSEL.
- Успешные ответы кэшируются на 10 минут, ошибки на 30 секунд; запросы ограничены, память кэша ограничена. При уходе со страницы карточки удаляются, устаревший ответ не переносится на другую игру.
- «На GGSEL» открывает собственную карточку внутри Steam. Только отдельное подтверждение оформления открывает настоящий сайт; заказ и оплату пользователь завершает там.

## Проверки

```powershell
bun test
bun scripts/check-live.ts
bun scripts/check-options-live.ts
bun scripts/millennium-check.ts plugin.list
bun scripts/millennium-check.ts plugin.status dev.steam.ggselprices
bun scripts/millennium-check.ts plugin.logs dev.steam.ggselprices
```

`check-live` обращается к публичному каталогу и проверяет несколько свежих предложений. Остальные тесты автономны и используют отдельно помеченный снимок публичных товаров, который не попадает в рабочий источник цен. Проверка Lua с подставленным HTTP покрывает ошибки и кэш; настоящий Lua HTTP дополнительно проверен внутри Millennium.

`millennium-check` — инструмент разработчика для локального MEP-сокета Windows через Bun FFI. Он не входит в `.star` и не требует сетевого сервера. Подробности исследования — в docs/RESEARCH.md; текущие результаты — в docs/END-TO-END-VALIDATION.md; изменения — в CHANGELOG.md. Автоматическая проверка 0.8.2: 57 тестов / 303 проверки, TypeScript и четыре секции Starlight. После обновления перезагрузите интерфейс Millennium и откройте страницу игры заново, если открытый WebView продолжает использовать предыдущий JavaScript.
